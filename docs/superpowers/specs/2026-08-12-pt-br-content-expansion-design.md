# pngparasvg.com 巴西葡语第一批内页设计规格

日期：2026-08-12

状态：待用户审核

目标市场：巴西

主要语言：巴西葡萄牙语（`pt-BR`）

## 1. 背景与目标

pngparasvg.com 已上线 PNG 转 SVG 浏览器工具，Google Search Console 已确认页面被发现或收录，但当前近三个月没有搜索展现和点击。网站目前只有首页，sitemap 也只声明首页，无法覆盖教程、图片矢量化和 Logo 转换等不同搜索意图。

第一批工作的目标是建立一个规模适中、可持续扩展的巴西葡语内容结构：保留首页作为核心转换工具，用指南中心和三篇实操指南覆盖三个不同搜索意图，并补齐基础信任页面。所有公开 SEO 内容必须随初始 HTML 返回，不依赖 JavaScript 执行后才生成。

第一批不以立即获得点击为验收条件。上线后继续建设第二、第三批，并从第一批上线日起滚动观察 28 天的收录、查询和展现数据。

## 2. 设计原则

1. 一个页面服务一个独立搜索意图；同义关键词合并到同一页，不建立关键词替换页。
2. 内容以帮助巴西用户完成任务为目标，不按固定字数填充，也不机械翻译。
3. 标题、正文、导航、FAQ 和内链全部写入静态 HTML。
4. JavaScript 只负责用户交互和图片转换，不负责生成可索引的主要内容。
5. 内容页先回答问题，再提供简化上传入口；首页保留完整转换设置。
6. 新页面必须通过主导航、指南中心、首页精选指南或正文相关推荐被普通用户访问，不能成为孤岛页面。
7. 不承诺所有图片都能无损矢量化；清楚说明自动描摹的适用范围和局限。

## 5. 信息架构与导航

采用“精简主导航＋指南中心”的结构。

主导航提供：

- `Converter`：指向首页工具区域。
- `Guias`：指向 `/guias/`。
- `FAQ`：首页指向首页 FAQ；内页可指向当前页 FAQ 或首页 FAQ，具体以用户上下文为准。

首页增加“精选指南”区，链接三篇第一批指南。指南中心首版包含：

- 一段说明本站指南解决什么问题的简介。
- 三张精选指南卡片。
- `Conversão básica`、`Vetorização de imagens`、`Logos` 三个主题分类。
- 每篇文章的独立摘要和普通 HTML 链接。

页脚按 `Ferramentas`、`Guias`、`Sobre` 分组，提供首页、指南中心、三篇指南以及隐私、条款、联系页面的可抓取链接。

每篇指南正文末尾提供 2–3 条语义相关链接，优先链接首页工具、指南中心以及另外一篇最相关指南。

## 6. 页面结构

### 6.1 首页

首页继续以完整 PNG 转 SVG 工具为主，不把 PDF 转 SVG 混入首页。现有视觉语言可以保留，但需要完成以下结构调整：

1. 唯一且明确的 H1。
2. 简洁的价值说明，准确描述浏览器本地处理和自动描摹。
3. 完整上传、参数调整、转换、预览和下载流程。
4. 三项核心优势。
5. 精选指南区。
6. FAQ。
7. 完整分类页脚。

### 6.2 指南内容页

采用已批准的 B 布局“内容引导后使用工具”：

1. 面包屑导航。
2. 唯一 H1 和直接回答搜索问题的导语。
3. 适用与不适用场景或转换前准备。
4. 正文前半段的简化上传入口。
5. 3–5 个实操步骤。
6. 真实、具体的转换示例或前后差异说明。
7. 常见失败原因与改进方法。
8. FAQ。
9. 相关推荐和回到完整工具的行动入口。

三篇指南不能使用仅替换关键词的同一正文结构。每篇必须体现独立知识价值：

- 转换教程侧重完整操作流程和文件准备。
- 图片矢量化教程侧重位图、路径、颜色层级和适用图像类型。
- Logo 专题侧重纯色、边缘、透明背景、低分辨率 Logo 和复杂渐变的处理。

### 6.3 信任页面

隐私政策必须准确反映实际处理方式，包括：

- 图片默认在浏览器本地处理，不上传到 pngparasvg.com 的服务器。
- 从指南页到首页传递文件时使用浏览器临时存储。
- 首页读取临时文件后清理；关闭或刷新造成的失败应安全降级为重新选取文件。
- 不声称完全无法收集任何数据；若部署平台自动产生日志或未来加入分析工具，应在启用前更新政策。

条款页应说明工具按现状提供、自动描摹存在局限、用户必须拥有上传素材的合法使用权，网站不为不当素材使用承担责任。

联系页显示 `contato@pngparasvg.com`，提供 `mailto:` 行动按钮，并说明适合联系的事项。第一批不加入网页表单。

## 7. 简化上传入口的数据流

指南页不复制完整转换器，只提供轻量文件入口。

流程如下：

1. 用户在指南页选择 PNG。
2. 页面验证文件类型，并显示缩略图与文件名。
3. 用户点击 `Converter agora`。
4. 浏览器将文件与必要元数据写入临时浏览器存储。
5. 页面跳转到首页工具锚点。
6. 首页读取文件，填充现有完整工具并立即删除临时记录。
7. 用户选择参数并开始转换。

约束：

- 数据不发送到网站服务器。
- 仅接受现有工具实际支持的图片格式；页面主叙述聚焦 PNG。
- 设置合理的文件大小限制，并对存储空间不足、隐私模式限制、格式错误和记录过期提供葡语提示。
- 任何传递失败都不得阻断首页工具，用户可以重新选择文件。
- 临时记录必须设置短有效期，不能作为长期图片保存机制。

具体使用 `sessionStorage`、`IndexedDB` 或二者组合由实施计划根据现有浏览器兼容性和图片大小限制决定；不得使用需要上传服务器的方案。

## 8. SEO 技术要求

每个正式 URL 必须：

- 返回可索引的独立静态 HTML 页面。
- 使用 `lang="pt-BR"`。
- 提供唯一的 `<title>`、meta description、H1 和自引用 canonical。
- 使用真实 `<a href>` 内链，不使用哈希路由模拟不同页面。
- 在 sitemap 中拥有唯一条目和准确的 `lastmod`。
- 保持 `index, follow`，除非测试发现特定错误页需要 `noindex`。
- 使用符合内容的 Open Graph 基础元数据。
- 保持结构化语义层级，不跳跃使用标题只是为了视觉字号。

结构化数据只在页面真实呈现对应内容时使用：

- 首页可保留与可见 FAQ 一致的 `FAQPage`。
- 指南页可使用 `Article` 或适合实际步骤的类型，但不得虚构作者、评分、日期或步骤。
- 面包屑可使用与可见导航一致的 `BreadcrumbList`。
- 信任页面不添加无意义的 FAQ 或 Article 标记。

第一批只建设 `pt-BR`，不创建 `/es/` 或英语版本，也不需要为不存在的翻译添加 `hreflang`。

## 9. 可访问性、性能与兼容性

- 导航、上传和主要按钮支持键盘操作，并有清晰焦点状态。
- 文件输入具有可访问标签；错误不能只通过颜色表达。
- 保持移动端可用，不出现水平滚动或遮挡。
- 不让新的指南卡片和脚本显著阻塞首页首屏。
- 指南页仅在用户操作简化上传入口时运行必要 JavaScript。
- 保留无 JavaScript 时可阅读、可导航的主要内容。
- 对当前项目支持的主流现代浏览器进行桌面与移动宽度检查。

## 11. 测试与验收

### 11.1 功能验收

- 首页现有 PNG 转 SVG转换、预览和下载功能仍能工作。
- 三篇指南的简化入口都能选择 PNG、显示预览并带到首页。
- 传递成功后首页清理临时记录。
- 文件格式错误、文件过大、临时存储失败和记录失效均显示可理解的葡语提示。
- 所有导航、面包屑、相关推荐、页脚和邮件链接可用。

### 11.2 SEO 验收

- 八个 URL 可直接访问并返回正确内容。
- 每页 title、description、H1、canonical 唯一且与页面意图一致。
- 关闭 JavaScript 后仍能看到主要正文和普通内链。
- sitemap 包含八个正式 URL，robots.txt 继续允许抓取并引用正确 sitemap。
- 没有空链接、测试链接、重复 canonical 或错误语言声明。
- 结构化数据与页面可见内容一致并通过语法检查。

### 11.3 视觉与内容验收

- 桌面和移动端均无明显溢出、遮挡或不可点击区域。
- 巴西葡语用词自然、前后一致，无中文、西语或机械翻译残留。
- 三篇指南内容实质不同，示例和建议符合 ImageTracer 自动描摹的实际能力。
- 不使用“任何图片都无损转换”等无法保证的表述。

## 12. 发布与观察

第一批完成并验证后即可发布，不等待 28 天。发布后：

1. 提交更新后的 sitemap。
2. 在 Search Console 对首页、指南中心和三篇指南进行 URL 检查；是否手动请求抓取由部署时状态决定。
3. 立即进入第二批 PDF 转 SVG真实工具的设计与开发，不因观察期停止建设。
4. 第一批上线约 5–7 天后，按计划建设第三批内容页。
5. 从第一批上线日起滚动观察 28 天，记录收录、巴西葡语查询、页面展现、平均排名和技术问题。

28 天数据用于调整标题、正文、内链和后续选题，不作为第二批开工前置条件。

## 13. 本批明确不做

- PDF 转 SVG 功能及页面；它属于紧接着的第二批。
- 西班牙语和英语页面。
- EPS、GIF 或其他新增格式转换器。
- 品牌 Logo、图标或其他第三方素材下载页。
- SVG 在线编辑器。
- CMS、数据库、用户账号、后端上传或联系表单。
- 仅替换关键词、内容高度相同的规模化页面。
- 为 Googlebot 和普通用户提供不同内容的动态渲染方案。
